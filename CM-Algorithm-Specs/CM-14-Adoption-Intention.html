Canonical Measure Algorithm Card

CM-14 — Adoption Intention and Long-Term Use

U — Use Adoption Intention Also known as: Intention to Use  ·  Willingness to Adopt  ·  Implementation Intent

Unit

Unit
TAM/UTAUT Behavioral Intention score (1–7, provisional anchor)
↑ Higher is better

Provider-reported intention to continue using the ambient AI scribe beyond the study period, including willingness to adopt and implementation readiness — an attitudinal (stated-intent) construct, distinct from adoption behavior itself (CM-13 Adoption Behavior and Utilization Rate), and distinct from recommendation likelihood and long-term-use satisfaction items, which were reclassified to CM-15 (Provider Satisfaction and Usability) as closer to satisfaction than to intention.

Gold Standard
A validated multi-item Technology Acceptance Model (TAM, Davis 1989) or Unified Theory of Acceptance and Use of Technology (UTAUT, Venkatesh 2003) Behavioral Intention construct — typically 3–4 items on a 7-point Likert scale. This is the theoretical framework referenced in the measure's own definition, not an instrument confirmed as fielded by any paper in this corpus (see Ambiguities).
Default / Practical
Single ad hoc Likert items actually observed in the literature — "intention to use," "willingness to adopt," "implementation intent," or "would you continue using this in long-term practice" — plus the operational proxy of license/seat relinquishment (% of clinicians who returned licenses).
⚠ Ambiguities to Resolve
  • This measure is theory-derived, not empirically grounded in this literature review. Unlike every other card in this set, no paper in the reviewed corpus reports fielding a validated multi-item TAM/UTAUT Behavioral Intention instrument with published psychometrics for this construct. The "UTAUT / TAM items" row in the source Measurement Methods table is a framework reference, not evidence of an instrument actually administered and scored this way — every corpus alias (Intention to Use, Willingness to Adopt, Implementation Intent, User Adoption Predictors, License Relinquishment) is a single ad hoc item or operational metric, not a scored multi-item construct. Do not present a TAM/UTAUT score computed from this design as if it replicates a corpus finding — it does not. Confidence in the specific item count, wording, and 1–7 anchor below is low.
  • Attitudinal vs. behavioral conflation. Stated intention and actual continued use are different constructs; license relinquishment is a real behavioral proxy but only captures full discontinuation, not gradations of intention short of that.
  • Boundary overlap with CM-15. Recommendation likelihood and long-term-use items were explicitly moved to CM-15 during corpus derivation. A survey wave that asks both intention and satisfaction items risks double-counting the same underlying construct if item wording is not kept distinct.
  • Scale-anchor ambiguity. No consistent Likert anchor (5-point vs. 7-point) appears across the papers that touch this construct; the 1–7 anchor above follows the classical TAM/UTAUT convention but is not corpus-confirmed.

Algorithm

1 Survey Instrument Scoring — Dose-Response Cohort Comparison Phase 0 / Phase 3 administration

Produces a cohort-level behavioral-intention score for each administration wave, compared across Suki utilization tiers. Unlike CM-01, a true Phase 0 baseline is meaningful here because "intention to adopt" can legitimately be asked before any use — the score is expected to increase (or hold, for already-high baselines) from Phase 0 (intention-to-adopt) to Phase 3 (intention-to-continue), most in the heaviest-utilization cohort.

Pseudocode
Phase 0 (T0, at/before go-live, all eligible providers): score[p, T0] = MEAN(intention item responses, 1-7) for provider p # NOTE: item set is provisional (TAM/UTAUT Behavioral Intention constructs) -- no corpus # paper reports a validated multi-item instrument actually fielded; theory-derived only Weeks 1-16: track Suki sessions per provider per week utilization_pct[p] = completed sessions / eligible encounters (rolling 4-week) tier[p] = HEAVY if utilization_pct[p] >= 0.70 MODERATE if 0.30 <= utilization_pct[p] < 0.70 LIGHT if utilization_pct[p] < 0.30 (assigned at week 4, held fixed) Phase 3 (T3, months 4-9, same respondents where possible): score[p, T3] = MEAN(intention item responses, 1-7) for provider p license_status[p, T3] = ACTIVE or RELINQUISHED For each tier T in {HEAVY, MODERATE, LIGHT}: cohort_score[T, T0] = MEAN(score[p, T0] for p in tier T) cohort_score[T, T3] = MEAN(score[p, T3] for p in tier T) dose_response_delta[T] = cohort_score[T, T3] - cohort_score[T, T0] relinquishment_rate[T] = COUNT(license_status == RELINQUISHED, p in tier T) / COUNT(p in tier T) dashboard_value = dose_response_delta[HEAVY] vs dose_response_delta[LIGHT] (expect HEAVY delta more positive than LIGHT delta; relinquishment_rate lowest in HEAVY)
Expected Trend — Behavioral Intention Score / Cohort / Wave

Cohort-mean intention score is projected to increase from Phase 0 (intention-to-adopt) to Phase 3 (intention-to-continue), most in the heavy-utilization cohort. This shape is a theoretical projection from the TAM/UTAUT dose-response logic used elsewhere in this measure family — no paper in this corpus reports this pattern directly for intention, so treat it as illustrative, not evidence-anchored.

Suki Data — Scoped Role

Suki's role for CM-14 is limited to utilization-cohort scaffolding and license/seat status. Session counts define the heavy/moderate/light dose-response cohorts, and seat status (active vs. relinquished) provides an operational behavioral corroboration signal. Suki has no native attitudinal or intention-survey data — adoption intention is a provider-reported psychological construct with no API analog.

Because no instrument for this construct is confirmed as validated within the reviewed literature, Suki data cannot substitute for or validate the missing instrument. The customer or research team must independently select a TAM/UTAUT-based instrument (or use a corpus-observed single-item proxy) and administer it on the schedule above.
