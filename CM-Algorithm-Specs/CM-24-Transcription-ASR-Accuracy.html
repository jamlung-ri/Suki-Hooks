Canonical Measure Algorithm Card

CM-24 — Transcription and ASR Accuracy

SQ — System Quality ASR / Transcription Quality ⚠ No Suki Data Source Available Also known as: Word Error Rate (WER)  ·  ASR Accuracy  ·  Medical Term Recall (MTR)  ·  Speaker Diarization Accuracy

Unit

Unit
Word Error Rate (%) — with Speaker Diarization Accuracy (%) as companion metric
↓ Lower WER is better

Word Error Rate (WER) is the percentage of words in an ASR-generated transcript that are incorrect relative to a human-transcribed reference, computed via minimum edit distance (substitutions + deletions + insertions) divided by total reference words. Speaker Diarization Accuracy is the percentage of transcript segments correctly attributed to the correct speaker (clinician vs. patient) and is reported alongside WER as this measure’s companion metric — both describe the technical fidelity of the raw transcript that every downstream note is built on.

This is the upstream quality gate: if the transcript is wrong, the generated note will be wrong regardless of how good the summarization/NLP layer is. It is a distinct measurement point from CM-08/CM-09/CM-10/CM-12 (note-level quality), which score the note, not the transcript that fed it.

Gold Standard
Human-transcribed reference transcript, produced by a professional medical transcriptionist blind to the ASR output, aligned word-by-word against the ASR hypothesis using standard edit-distance tooling (e.g., NIST sclite, jiwer).
Default / Practical
None established. No fallback or proxy WER methodology is published in the corpus or in any commercial ambient-AI vendor’s public documentation, Suki included — see Data Requirements below.
⚠ Ambiguities to Resolve
  • No data source is currently available to populate this measure. Per the literature review’s Key Note: no commercial ambient-AI vendor — Suki included — publishes WER or diarization accuracy figures. This is a documented industry-wide opacity pattern dating to van Buchem 2021, not a Suki-specific gap. As of this writing there is no reference transcript, ASR decoder/confidence output, or third-party WER benchmark accessible for Suki sessions, so this measure cannot currently be computed on Suki data (see Data Requirements and Suki Data Scope below).
  • Only 3 papers in the entire corpus measure this directly (Anderson 2025 simulation; Wang 2025 evaluation framework; van Buchem 2021 scoping review) — the published evidence base for expected WER/diarization ranges in ambient clinical scribes generally, not just for Suki, is thin.
  • Upstream/downstream conflation risk. ASR errors propagate into note-quality measures (CM-08, CM-09, CM-10, CM-12) with no way to isolate how much of a note-level error originated in the transcript versus downstream summarization — without WER data, Transcript Error Transmission Rate (Anderson 2025) also cannot be computed.
  • Word-level scoring is itself ambiguous for clinical speech. Medical terminology, abbreviations, and multi-speaker crosstalk complicate standard WER alignment; Wang 2025’s Medical Term Recall (MTR) submetric exists specifically because generic WER under- or over-penalizes clinical-vocabulary errors depending on tokenization choices. A fixed alignment/tokenization protocol would need to be chosen before any number is reported.

Algorithm

1 Word Error Rate & Diarization Accuracy — Reference Formula Standard ASR evaluation method — not currently computable on Suki data

The standard, well-established method the field uses to score ASR transcription quality against a reference transcript. The formula itself is not in question — it is the universal WER definition used across speech-recognition research. What is in question is whether the required reference-transcript and ASR-internal data exist for Suki sessions today; they do not (see Data Requirements below).

Units in this Algorithm
Primary
Word Error Rate (%)
Edit-distance-based transcription error rate, scored per session against a human reference transcript, reported as a cohort mean and distribution.
Secondary
Speaker Diarization Accuracy (%)
% of transcript segments correctly attributed to the correct speaker, scored against ground-truth speaker-turn labels.
Secondary
Medical Term Recall (MTR)
% of clinical vocabulary (drug names, anatomical terms, abbreviations) correctly transcribed — a submetric of WER that isolates clinically consequential errors from generic ones.
⚠ Requires a separate clinical-vocabulary tagging pass over the reference transcript; not a byproduct of standard WER tooling.
Word Error Rate=Substitutions + Deletions + InsertionsTotal Words in Reference Transcript × 100
Alignment method: minimum edit distance (Levenshtein) word alignment, ASR hypothesis vs. human reference Reporting grain: per session, aggregated to cohort mean + distribution (WER varies with audio quality and speaker overlap)
Diarization Accuracy=Correctly Attributed Speaker-SegmentsTotal Speaker-Segments × 100
Requires ground-truth speaker-turn labels (who spoke each segment), scored independently of word-level WER

Pseudocode — Standard WER + Diarization Scoring
for session in sample: hypothesis = session.asr_transcript # NOT currently exposed by Suki reference = session.human_reference_transcript # NOT currently produced for Suki sessions # 1. Word Error Rate alignment = MIN_EDIT_DISTANCE_ALIGN(hypothesis.words, reference.words) substitutions = COUNT(alignment.substitution_ops) deletions = COUNT(alignment.deletion_ops) insertions = COUNT(alignment.insertion_ops) wer[session] = (substitutions + deletions + insertions) / COUNT(reference.words) * 100 # 2. Speaker Diarization Accuracy speaker_labels_true = session.ground_truth_speaker_turns # NOT currently collected speaker_labels_asr = session.asr_speaker_turns # NOT currently exposed diarization_acc[session] = COUNT(correctly_attributed_segments) / COUNT(total_segments) * 100 # 3. Medical Term Recall (submetric) clinical_terms = TAG_CLINICAL_VOCAB(reference.words) # separate annotation pass mtr[session] = COUNT(clinical_terms correctly transcribed) / COUNT(clinical_terms) * 100 dashboard_value = { "wer_mean": MEAN(wer), "diarization_acc_mean": MEAN(diarization_acc), "mtr_mean": MEAN(mtr) } # ⚠ Every input marked "NOT currently exposed / collected" blocks this pipeline from running today.

Suki Data — Scoped Role

Suki provides the raw input a WER pilot would require — session audio — but does not currently expose ASR-internal outputs (decoder confidence, word-level alignments) or any reference-transcript / human-transcription workflow needed to compute Word Error Rate or Speaker Diarization Accuracy. No data source currently exists to populate this measure.

This is not evidence of a Suki-specific weakness: no commercial ambient-AI vendor publishes this measure today — a documented industry-wide opacity pattern dating to van Buchem 2021. Populating this measure for Suki would require either a dedicated benchmarking pilot (commissioning reference transcripts for a sample of sessions and scoring against them) or a data-sharing / API addition exposing ASR decoder output and ground-truth speaker labels.
