Individual Algorithm Cards

CM-01
Clinician Burnout
PFI Work Exhaustion subscale (1–5), lower is better. Survey-based, dose-response design across Suki utilization tiers.
NB Provider Wellbeing
CM-02
Cognitive Task Load
NASA-TLX / Physician Task Load (PTL) survey score. Pre/post-deployment waves, bundled engagement item with CM-18.
NB Provider Wellbeing
CM-03
Professional Fulfillment
PFI Professional Fulfillment subscale. Secondary/exploratory, bundled with CM-01 — expected null (dissociation finding).
NB Provider Wellbeing Secondary / Exploratory
CM-04
Documentation Time
Minutes per encounter. EHR audit-log gold standard; Suki session timestamps as native fallback.
NB Documentation Efficiency
CM-05
After-Hours Documentation
After-hours minutes per provider per month (Pajama Time). EHR audit-log; per-provider scheduled hours.
NB Documentation Efficiency
CM-06
Chart Closure Timeliness
% of encounters with notes closed within 24 hours. Suki draft-availability rate vs. EHR signature-confirmed closure.
NB Documentation Efficiency
CM-07
Total EHR Time
Total EHR minutes per encounter across all task types — documentation, inbox, orders, results review.
NB EHR Efficiency
CM-08
Note Completeness and Omission Rate
PDQI-9/PDSQI-9 Thoroughness domain. Human rating + LLM-as-judge, mirrors CM-09's pilot design for the opposite error type.
NB Information Quality Pilot / Calibration
CM-09
Note Inaccuracy Rate
% of notes with ≥1 fabricated or incorrect element. PDQI-9/PDSQI-9 Accuracy pilot, human rating + LLM-as-judge.
NB Information Quality Pilot / Calibration
CM-10
Note Quality Overall
Composite PDQI-9/PDSQI-9 rollup across all domains, including CM-08 Thoroughness and CM-09 Accuracy.
NB Information Quality Composite / Rollup
CM-11
Note Length and Verbosity
Word/character count and lexical diversity, fully automated. Direction not asserted — read alongside CM-08/CM-10.
NB Information Quality
CM-12
Automated NLP Evaluation Metrics
ROUGE/BERTScore/F1 vs. reference text — a calibration tool for the rating pipeline, not a Suki-adoption outcome.
NB Information Quality Methodological Tool
CM-13
Adoption Behavior and Utilization Rate
Ambient Notes Created ÷ EHR Appointments Scheduled. Real, validated Suki Admin Console BigQuery — not an Epic-derived measure.
U — Use
CM-14
Adoption Intention and Long-Term Use
TAM/UTAUT behavioral-intention score. Zero corpus papers measure this directly — theory-derived, not empirically grounded.
U — Use Low Confidence
CM-15
Provider Satisfaction and Usability
System Usability Scale (SUS) score, 0–100. Early-experience vs. mature-use wave comparison, no true pre-exposure baseline.
US — User Satisfaction
CM-16
Provider Trust in AI
Trust/confidence Likert score plus qualitative verification-behavior coding. Only 3 papers measure this construct.
U — Use
CM-17
Patient Experience
PDRQ-9 relationship-quality score. Targeted multilingual-cohort design via transcript lang_id (H4 pathway).
NB Organizational Impact Tier 3 — 5/12
CM-18
Physician-Patient Interaction
Consultation duration (Suki-native) + post-encounter engagement Likert + exploratory talk-time/turn-taking.
NB Organizational Impact Tier 3 — 6/12
CM-19
Clinical Patient Safety
Documentation-completeness vs. clinical-action linkage (Castro 2025 replication). Scope-narrowing applies — see card.
NB Organizational Impact Monitor — 6/12
CM-20
Financial Productivity
Three operationalizations: wRVUs per week, paid revenue per month, and E/M Level 4–5 share.
NB Financial Productivity
CM-21
Coding Accuracy
Three operationalizations: ICD-10 coding depth, Suki suggestion match rate (native data), and denial rate.
NB Coding Accuracy
CM-22
Patient Volume & Throughput
Completed encounters per provider per week. Higher is better — volume freed by documentation efficiency.
NB Patient Volume
CM-23
Implementation Barriers and Workflow Fit
FIM/AIM/IAM composite score plus qualitative barrier-frequency coding. Retains a non-adopter cohort by design.
SerQ — Service Quality
CM-24
Transcription and ASR Accuracy
Word Error Rate / diarization accuracy formula given, but no vendor (including Suki) currently publishes this data.
SQ — System Quality No Data Available
CM-25
Evaluation Methodology Quality
ICC/evidence-tiering for source-paper rigor. Meta-measure — flagged as a candidate for removal from the canonical set.
Meta-Measure Candidate for Removal
