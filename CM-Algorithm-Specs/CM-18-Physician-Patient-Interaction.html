Canonical Measure Algorithm Card

CM-18 — Physician-Patient Interaction Quality

OI — Organizational Impact Tier 3 — 6/12 (H1 = ● for this measure) Also known as: Doctor-Patient Interaction Time  ·  Undivided Attention to Patients  ·  Consultation Duration  ·  Time Searching for Information

Unit

Unit
Consultation duration (minutes) — primary representation
↑ Higher = more face time

A behavioral measure of the clinical encounter itself — face-to-face time, clinician attentiveness, screen time, and perceived engagement during the visit. Distinct from CM-17 (the patient's own report of relationship quality) and from CM-22 (patient volume/throughput — "time does not measure quality," so "patients seen per hour" was explicitly reassigned out of this measure).

Multiple Operationalizations (this card covers 3)
1 ↑ Higher Consultation duration (minutes) — direct timing, Suki-native via transcript timestamps
2 ↑ Higher Post-encounter engagement Likert item (1–5) — "I had undivided attention to give to my patient"
3 Context-dependent Talk-time / turn-taking ratio (clinician : patient speech time) — exploratory, unvalidated
Gold Standard
Direct observation/timing of doctor-patient interaction time (Shuaib 2021, human-scribe comparator: interaction time doubled, throughput +39%) and validated engagement survey items (Duggan 2025, Stults 2025: "I have undivided attention to give to my patients").
Default / Practical
Consultation duration from Suki transcript timestamps — the single strongest Suki-native data point for CM-18, directly matching one of the measure's four defined methods with no additional instrumentation, comparable in directness to CM-06's session-completion timestamps.
⚠ Ambiguities to Resolve
  • No single validated instrument. Unlike CM-01/02/03/17, CM-18 has no PFI/PDRQ-9-style scale — the literature uses custom Likert items, primarily from Duggan 2025 and Stults 2025.
  • Shuaib 2021's magnitude is a ceiling, not an expectation. It is a human-scribe comparator (doubled interaction time, +39% throughput) and likely represents an upper bound on what ambient AI alone would achieve.
  • "Time searching for information" is entirely out of scope for Suki. This defined method requires in-encounter EHR active time (clicks/keystrokes during the visit window) — Suki has no visibility into EHR screen activity at all.
  • Talk-time/turn-taking is exploratory only. The transcript contains the raw data, but no validated methodology has been applied to Suki transcripts for this purpose — report only as a secondary/corroborating signal, not equivalent to observed attentiveness.
  • H10/H11 exposure metadata missing. Same gap as CM-02 — sessions need a flag for whether a pre-visit summary (H10) or in-visit chart Q&A (H11) was used, to isolate whether either feature changed in-encounter behavior.

Algorithm

1 Dashboard Metric — Consultation Duration (Cohort Average) Suki-Native Lead metric — no new instrumentation

Computes encounter length directly from transcript start/end timestamps and reports the cohort-average consultation duration, pre/post Suki adoption and by utilization tier. This is the lead quantitative signal for CM-18 — it requires no new instrumentation and directly matches one of the four defined CM-18 measurement methods ("Consultation duration / direct timing").

Units in this Algorithm
Primary
Consultation duration (minutes)
Per-session encounter length = (timestamp of final transcript segment) − (timestamp of first transcript segment). Reported as a cohort mean, pre/post adoption and by utilization tier.
Secondary
Suki utilization tier (heavy / moderate / light)
Standard cohort definition (as CM-01/02/03/06) for dose-response comparison against self-report engagement items in Algorithm 2.
Secondary
H10/H11 exposure flag
Whether the session used a pre-visit summary (H10) or in-visit chart Q&A (H11) — enables a within-provider comparison of consultation duration with vs. without these features.
⚠ Not currently exposed at the session level — same gap noted in CM-02's report.
Cohort Mean Consultation Duration=∑ (last_segment_ts − first_segment_ts) across sessionsCOUNT(sessions where status = completed)
Per session: duration_minutes = MINUTES(transcript[-1].end_ts - transcript[0].start_ts) Report: cohort mean, pre/post adoption, by utilization tier, and split by H10/H11 exposure flag (where available) Cross-check: compare against EHR-side encounter duration (scheduled or actual) where available
Pseudocode
For each session s where s.status == "completed": duration[s] = MINUTES(s.transcript[-1].end_ts - s.transcript[0].start_ts) tier[s] = utilization_tier(s.provider) exposure[s] = { "h10": s.used_previsit_summary, "h11": s.used_chart_qa } # if available dashboard_value = { "overall_mean" : MEAN(duration[s] for s in completed_sessions), "by_tier" : { t: MEAN(duration[s] for s in completed_sessions if tier[s] == t) for t in {"heavy","moderate","light"} }, "by_h10_h11" : { flag: MEAN(duration[s] for s in completed_sessions if exposure[s][flag]) for flag in {"h10","h11"} } # if exposure data available } # Report pre/post adoption and by cohort; use Shuaib 2021 (doubled) as a ceiling reference, not a target
2 Survey Instrument Scoring — Post-Encounter Engagement Likert Item Bundled with CM-02 NASA-TLX/PTL administration

Adds a single post-encounter or end-of-shift Likert item (e.g., "Today, documentation did not prevent me from being fully present with my patients," modeled on Duggan 2025/Stults 2025) bundled with whatever CM-02 NASA-TLX/PTL administration is already planned — the timing requirements are similar (close to the encounter), so a single administration mechanism can carry both measures.

Primary
Engagement Likert item score (1–5, higher = better)
Single item, custom (no validated CM-18 instrument exists) — e.g., "I had undivided attention to give to my patients today" or "Documentation did not prevent me from being fully present." Reported as a cohort mean per administration wave.
Secondary
Suki utilization tier (heavy / moderate / light)
Same cohort definition as Algorithm 1 and as CM-01/02/03/06 — reused, not recomputed.

3 Exploratory — Talk-Time / Turn-Taking Distribution Secondary / corroborating signal only

Uses transcript speaker/segment structure to compute the ratio of clinician-speech time to patient-speech time, and simple turn-taking patterns, as a rough structural proxy for "attentiveness." Reported only as exploratory corroboration alongside Algorithms 1 and 2 — not as a primary or standalone outcome.

Units in this Algorithm
Secondary
Clinician : patient speech-time ratio
Per session, the proportion of total transcribed speech time attributed to the clinician vs. the patient, derived from transcript speaker/segment structure.
⚠ Pipeline gap: no validated methodology has been applied to Suki transcripts for this purpose. This requires methodological work, not just data access, before it is reportable — treat as hypothesis-generating only.

Do not present as equivalent to observed attentiveness.

Suki Data — Scoped Role

Consultation duration is Suki-native and directly matches a defined CM-18 method — no new instrumentation required, and the strongest Suki signal for this measure (comparable in directness to CM-06's session-completion timestamps). Talk-time ratio is computable from the same transcript data but is exploratory/unvalidated.

The engagement Likert item has no Suki-native equivalent and must be bundled with CM-02's administration. "Time searching for information" — one of CM-18's four defined methods — is entirely out of scope for Suki and requires the same EHR audit-log request already made for CM-02; this is a smaller EHR-data ask overall than CM-02 or CM-06, since it can be requested once and used for both measures.
