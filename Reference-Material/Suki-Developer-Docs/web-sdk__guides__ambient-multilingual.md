The Web SDK supports the
**Multilingual**
capability for all ambient sessions you create. Patients and providers can speak in their preferred language during the conversation; the SDK generates the clinical note in English.
The SDK enables multilingual capability automatically when you create an ambient session. You don’t need to configure anything.
Learn more about multilingual capability in the
Multilingual support
capability guide.
